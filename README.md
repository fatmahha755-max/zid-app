# صانع باقات رواق القهوة
نموذج مسار بصفحتين: index.html لوحة التاجر، store.html واجهة العميل.
شغّل `python3 -m http.server 8766 --directory dist` من مجلد المشروع.
البيانات والصور من حزمة masar-demo-store الخيالية. اقتراحات قواعد ثابتة قابلة للتعديل، وليست نموذج ذكاء اصطناعي.
تُحفظ الباقات في localStorage بالمتصفح نفسه. الموقع عام لتجربة النموذج، وليس لوحة إدارة متجر حقيقي. السلة مؤقتة في الصفحة ولا تتضمن شراء أو دفع.
التحقق: `node tests/bundles.cjs`.
الهامش تقديري (سعر الباقة ناقص تكاليف المنتجات مقسومًا على سعر الباقة)، دون مصروفات أو تسويات ضريبية. تُحسب السعة لكل خيار منتج، مع كميات الباقة. يُمنع اختلاف مقاس 01/02 للقطارات والفلاتر.
